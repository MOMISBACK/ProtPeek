# ProtPeek Android 0.1.0 — prototype

- Central protein/gene/organism and article-title/DOI/PMID search.
- Existing PDB and AlphaFold structures with explicit source identity and exact
  protein/primary-publication association checks.
- Approved GroEL icon and the latest minimal blue ProtPeek appearance.
- Real Mol* molecular rendering, local file opening, customization and native
  PNG/mmCIF saving and sharing.
- Automatic system light/dark appearance, bounded 32 MiB file transport, native
  document handling and local recent remote identifiers.

This is a prototype. Search providers may be unavailable or incomplete. Recent
items are not an offline structure library. GRO opens its first frame only.
PNG and mmCIF exports have different contents: images preserve appearance;
coordinate files do not preserve colors or camera. No new structure prediction
is computed. See android/README.md and the release metadata for build provenance
and validation details.
