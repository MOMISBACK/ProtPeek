# Security policy

## Supported version

Security fixes currently target the latest code on the `main` branch and the
latest published ProtPeek release.

## Reporting a vulnerability

Please do not open a public issue for an exploitable vulnerability or include
private molecular data in a report. Use GitHub's **Report a vulnerability**
workflow for this repository to open a private Security Advisory:

<https://github.com/MOMISBACK/ProtPeek/security/advisories/new>

Include affected versions, impact, reproducible steps, and a minimal safe
proof of concept. Receipt and remediation timing depend on maintainer review;
do not disclose the issue publicly before a fix or coordinated disclosure has
been agreed.
